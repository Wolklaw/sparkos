# Spark Emoji

The SparkOS emoji and symbol picker. It is bound to Meta+. (Windows key and
full stop): a small popup where you type to search, in English and French at once, and Enter or a click
copies the character. Version 0.1.0.

## Using it

| | |
|---|---|
| Meta+. | open the picker (again while it is open: close it) |
| type | search at once; accents and case don't matter (`coeur`, `ÉTOILE`); `U+1F44D` finds a code point |
| Enter | pick the first result |
| Down, arrows | move into the grid and around it; Enter picks |
| click | pick |
| right click | skin tones for a hand or a person |
| Esc | clear the search, then close |

Tabs: recently used, the nine emoji categories, and Symbols (arrows, maths, currency, accented letters
and other signs). The hand at the bottom sets one skin tone for everything.

## Copying and pasting

A pick is always copied to the clipboard, and the window you were in is put back in front.

Pasting into that window is a separate permission. Wayland lets no program type into another program's
window, so Spark Emoji asks the desktop for a keyboard-only session through the XDG desktop portal
(RemoteDesktop). Click **Turn on pasting** once; the desktop asks, and remembers the answer. After
that a pick also presses Ctrl+V (Ctrl+Shift+V is available for terminals in the code but not used by
the picker yet). If the desktop says no, or has no such portal, Spark Emoji copies and says "Press
Ctrl+V to paste it".

What has been tested: the portal calls, against a fake portal. What has not: a real portal and
its permission dialog. 

## The command line

```
spark-emoji                   open the picker
spark-emoji --search QUERY    print the matches (character, English name, French name); no window
spark-emoji --self-test       check the data, the search, the emoji font, GTK and the portal
spark-emoji --version
```

## Settings and files

`~/.config/spark-emoji/settings.json` (skin tone, pasting on or off, the portal's restore token,
glitch effect), `~/.local/state/spark-emoji/recent.json` (recently used) and the log in the same folder.
`SPARK_LANG=fr` or `en` overrides the language; otherwise `LANG` decides.

## Installing

```
bash install.sh --user              just you, into ~/.local (no Meta+. shortcut: that is system-wide)
bash install.sh --user --uninstall
sudo bash install.sh --deps         the whole system (the image build does this)
```

In the SparkOS image, `files/scripts/spark-emoji.sh` also gives the app Meta+. (the Spark compositor binds it).

## Data

`sparkemoji/data/emoji.json` and `symbols.json` are generated by `tools/make_data.py` from the Unicode
emoji data and CLDR annotations (Unicode-3.0; see THIRD-PARTY.md). They are committed, so nothing is
downloaded when the image is built. To update to a new Unicode version:

```
python3 tools/make_data.py --fetch /tmp/emoji-sources
python3 tools/make_data.py --sources /tmp/emoji-sources
```
